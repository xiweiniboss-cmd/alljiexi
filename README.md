# alljiexi

解析站总入口：粘贴任意平台的分享文字或链接，自动识别平台并跳到对应的解析站（链接已预填）。

- 纯静态页面，部署在 Cloudflare Pages，输出目录 `public/`，不需要构建命令
- 识别全部在浏览器里完成，没有后端、没有统计代码；链接通过 `#url=` 带给解析站，不进服务器日志
- 解析站那边只把链接填进输入框，不会自动解析，人机验证照常由用户完成

## 改站点

只改 `public/sites.mjs`：网址、域名列表、`enabled`（`false` 时能识别但只提示「还没上线」）。

## 测试

```
npm test
```

用真实格式的分享文案（抖音、快手、小红书、B站、YouTube、TikTok、微博）测试链接抽取和平台识别。
